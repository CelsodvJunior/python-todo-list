# 📝 To-Do List em Python

Este projeto é um gerenciador simples de tarefas (to-do list) feito em Python, com persistência de dados em arquivo JSON. Ideal para praticar lógica de programação, funções, manipulação de listas e dicionários.

## 🚀 Funcionalidades

- Adicionar novas tarefas à lista
- Visualizar todas as tarefas numeradas e com status
- Marcar tarefas como concluídas (exibindo `[x]` ao lado)
- Persistência automática das tarefas em arquivo JSON
- Sair do programa

## 💾 Persistência

As tarefas são salvas automaticamente no arquivo `tarefas.json` sempre que você adiciona ou marca uma tarefa como concluída. Ao iniciar o programa, as tarefas são carregadas desse arquivo, garantindo que nada seja perdido entre execuções.

## 💻 Como Executar

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/CelsodvJunior/python-todo-list.git
   ```

2. **Navegue até a pasta do projeto:**

   ```bash
   cd python-todo-list
   ```

3. **Execute o programa principal:**
   ```bash
   python main.py
   ```

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Conceitos:** Funções, listas, dicionários, laços de repetição (`while`, `for`), módulos, manipulação de arquivos JSON
